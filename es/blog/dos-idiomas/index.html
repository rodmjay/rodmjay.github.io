Este blog es una carpeta de archivos markdown en el mismo repositorio que el resto del sitio. Una compilación pequeña los convierte en páginas y GitHub Pages las publica. Cada artículo tiene una versión en inglés y otra en español, y ninguna se publica sola.

#Por qué los dos, siempre

Muchas de las personas con las que trabajo leen primero en español. Una traducción automática se nota, así que cada versión se escribe a mano, y el sitio nunca muestra un cambio de idioma que lleve a una página que no existe.

  • Cada artículo son dos archivos que comparten un id.
  • Cualquiera de los dos puede esperar como borrador.
  • La compilación se detiene si un artículo publicado no tiene su par.

Escribirlo dos veces es justamente la idea. La segunda pasada encuentra lo que la primera escondía.

#El archivo

El encabezado trae todo lo que necesita el índice. El id une el archivo en inglés con su par en español.

Publicar son dos comandos:

node scripts/build-blog.mjs   # fails if a live post has no twin
git push                         # GitHub Pages publishes it
